# Security and privacy

Pitchform is designed to be local-first:

- audio stays on the user's computer;
- no account, cloud upload, analytics, or telemetry is required;
- the Tauri shell uses no network capability;
- project files contain the source fingerprint, analysis, edits, and an embedded WAV asset so they can be reopened offline.

Please report security issues privately to the repository owner before opening a public issue. Do not attach private recordings or project files to a public report.
