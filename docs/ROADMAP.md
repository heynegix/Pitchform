# Roadmap

## v0.1 — focused local MVP

- [x] application shell and CI
- [x] local audio import, playback, seek, loop
- [x] waveform, pitch curve, piano-roll note blobs, playhead
- [x] monophonic F0 detection and note segmentation
- [x] note selection, vertical drag, snap/fine adjustment
- [x] undo/redo and original/corrected A/B preview
- [x] WAV export and `.pitchform` save/open
- [x] higher-quality pitch-shift renderer
- [ ] real-world vocal evaluation and artifact tuning

## v0.2

Note split/merge, pitch drift and vibrato controls, correction strength, scale/key snap, keyboard shortcuts, autosave, and MIDI export.

## v0.3+

Better segmentation, formant preservation, sibilant handling, batch processing, and an interchangeable DSP backend.

## Deliberately deferred

Polyphonic DNA-style editing, realtime autotune, live microphone correction, VST3/AU/ARA, collaboration, accounts, cloud sync, and generative AI are not v0.1 work.
